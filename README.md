# Cool Paint Project

A personal collection of digital paint studies, color palettes, and small
canvas experiments. Nothing serious here — just a place where I keep my
favorite palettes and a few color-mixing sketches I'm happy with.

## What's in here

- Palette notes and hex collections I keep coming back to
- Small canvas experiments and brush tests
- A few tiny Python scripts I use to generate palette variations
  (that's most of the code in this repo — it's just color utilities)

## Tools

Mostly Procreate and a bit of Krita. Occasionally I script small color
utilities in Python to auto-generate lighter/darker steps of a base color,
and I keep those scripts here so I don't lose them.

## Status

This repo is mostly for personal use — a quiet corner of the internet for
my paint stuff. Feel free to look around, but there isn't much to see yet.
