# Chassis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap every strategy in a fixed 6-layer decision chassis: market context (1y look) → regime allowlist → fee gate → signal → vol-target×conviction sizing → order. Evolution tunes only the signal.

**Architecture:** `bot/market/context.py` (vectorized MarketContext + regime classifier), `ChassisStrategy` subclassing `FeeAwareStrategy` with entry hooks, `PaperAccount.open_position(fraction=...)`, backtest engine honors `_entry_fractions`. Spec: `docs/superpowers/specs/2026-08-15-chassis-design.md`.

**Tech Stack:** pandas/numpy, house test runner `python tests/run_tests.py`.
